## 1. Business Strategy & Planning

### Prompt 1: Market Opportunity Analysis
```
You are a senior strategy consultant. Analyze the following business idea for market opportunity:

Business Idea: [INSERT IDEA]
Target Market: [INSERT MARKET]
Current Stage: [INSERT STAGE]

Provide:
1. Market size estimate (TAM/SAM/SOM) with reasoning
2. Top 5 competitors and their weaknesses
3. Unique value proposition suggestions
4. Key risks and mitigation strategies
5. Recommended first 90-day validation steps
6. Pricing strategy recommendations

Be specific, data-oriented where possible, and practical.
```

### Prompt 2: Business Model Canvas Generator
```
Act as a business model expert. Create a complete Business Model Canvas for:

[DESCRIBE YOUR BUSINESS]

Output in a clear table or structured format covering all 9 blocks:
- Customer Segments
- Value Propositions
- Channels
- Customer Relationships
- Revenue Streams
- Key Resources
- Key Activities
- Key Partnerships
- Cost Structure

Also suggest 3 alternative revenue models and their pros/cons.
```

### Prompt 3: 12-Month Growth Roadmap
```
You are a growth advisor. Create a detailed 12-month growth roadmap for a [BUSINESS TYPE] starting from [CURRENT STATE].

Include:
- Monthly milestones
- Key metrics to track
- Resource requirements
- Potential bottlenecks and solutions
- Contingency plans
```

## 2. Marketing & Copywriting

### Prompt 4: High-Converting Landing Page Copy
```
Write complete landing page copy for [PRODUCT/SERVICE].

Target audience: [AUDIENCE]
Main benefit: [BENEFIT]
Price point: [PRICE]

Structure:
1. Headline (3 variations)
2. Subheadline
3. Problem agitation
4. Solution introduction
5. Benefits (5-7 with proof points)
6. Social proof section
7. Pricing & offer
8. FAQ (8 questions)
9. Strong CTA variations
10. Email sequence (3 emails)

Use persuasive but ethical language. Focus on outcomes.
```

### Prompt 5: Viral Content Hook Generator
```
Generate 20 high-engagement hooks for [PLATFORM: LinkedIn/X/TikTok/Xiaohongshu] about [TOPIC].

Each hook should:
- Grab attention in first 3 seconds/line
- Create curiosity or emotional response
- Lead naturally to the content
- Be optimized for the platform algorithm

Also explain why each hook works.
```

## 3. Content Creation

### Prompt 6: Comprehensive Blog Post
```
Write a comprehensive, SEO-optimized blog post on [TOPIC].

Requirements:
- 2000+ words
- Target keyword: [KEYWORD]
- Structure with H2/H3
- Include practical examples
- Add actionable takeaways
- Suggest 5 internal linking opportunities
- Meta description and title variations
```

### Prompt 7: Social Media Content Calendar
```
Create a 30-day social media content calendar for [NICHE/BUSINESS].

Platforms: [LIST PLATFORMS]
Goal: [GOAL]

For each day provide:
- Content type
- Hook
- Full post text
- Hashtags
- Visual suggestion
- Best posting time

Focus on value-first content that builds authority.
```

## 4. Product Development

### Prompt 8: Digital Product Ideation
```
Generate 15 digital product ideas for [NICHE] that can be created with AI assistance.

For each idea:
- Product name
- Description
- Target buyer
- Price range
- Creation difficulty (1-10)
- Estimated time to create
- Why it would sell
- Unique angle
```

```

[LIST FEATURES]

Recommend the MVP feature set and a 6-month roadmap.
```
